# Reflection and Learning Log

## What Was Built

I built an MVP version of the Student Support Insights Tool using Python, Streamlit, pandas, and Plotly. The tool loads learner survey data, validates it, visualises trends, identifies support-risk learners, and generates recommendations.

## Main Challenges

1. Keeping the project focused on the MVP.
2. Designing support-risk logic that is understandable and ethical.
3. Ensuring the tool met all assignment requirements without adding unnecessary features.
4. Explaining data ethics clearly.

## Key Decisions

1. Synthetic data was used to avoid privacy risks.
2. Rule-based support scoring was used to keep decisions explainable.
3. Streamlit was selected because it supports fast development of a working data app.
4. Human review was kept in the process to avoid harmful automated decisions.

## Future Improvements

1. Add a secure survey form.
2. Add user authentication.
3. Store learner data in a secure database.
4. Add role-based dashboards for staff, tutors, and managers.
5. Add better export options such as PDF reports.
